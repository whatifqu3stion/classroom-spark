# README screenshot provenance

These four PNGs are selected from a 34-view capture of the actual Boardwork frontend at commit `6037a20a1b5baff6b9d6d79f81890e8a2145258c`.

| File | Screen | Capture viewport |
| --- | --- | --- |
| `homebase.png` | Saved classroom Homebase | 1440 × 1000 |
| `activity-editor.png` | Activity preparation and editing | 1440 × 1000 |
| `student-presentation.png` | Student activity with countdown | 1440 × 1000 |
| `curriculum-review.png` | Draft source review and approval | 1440 × 1000 |

The PNGs are unchanged copies of the original captures. The interface was rendered in Chromium using prewritten illustrative classroom data and intercepted API requests. No real student records, API credentials, paid generation requests, or backend mutations were involved. The examples do not demonstrate the quality of model-generated content.

The curriculum capture supplies synthetic source data and the protected-setup state to show the review interface. It does not imply a public deployment has access protection or that a live publisher import succeeded. External resource players were not loaded. The sample clock was fixed for a stable capture.

This directory intentionally contains a small selection for the repository's product story rather than every screen or settings panel.
