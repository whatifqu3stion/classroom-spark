# Boardwork presentation fonts

These font assets are bundled for the currently exposed presentation
appearances and are licensed under the SIL Open Font License 1.1:

- Inter
- DM Sans
- DM Serif Display
- Atkinson Hyperlegible
- IBM Plex Sans
- IBM Plex Serif

Inter includes the 400, 500, 600, and 700 weights used by the workspace and
presentation surfaces.

Legacy appearance families continue to use explicit system/script fallbacks.
They are not bundled because they are no longer exposed as selectable
appearances.
