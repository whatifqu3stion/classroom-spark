# Boardwork presentation fonts

These font assets are bundled for the teacher workspace and Boardwork
presentation surfaces. They are licensed under the SIL Open Font License 1.1:

- Inter

Inter includes the 400, 500, 600, and 700 weights used by the workspace and
presentation surfaces. Presentation uses the original Inter 700 heading and
500 body pairing.

Saved legacy appearance choices use an explicit multilingual fallback stack,
including a deterministic local DejaVu Sans fallback before the system stack.
They are not bundled because typography is no longer selectable, and no remote
font service is used by presentation or PNG export.
