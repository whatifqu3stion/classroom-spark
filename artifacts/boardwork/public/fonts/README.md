# Boardwork font assets

These font assets are bundled locally. No remote font service is required for
the teacher workspace, presentation, or PNG export.

## Presentation families

The following files are official Google Fonts repository distributions. Both
are normal-style, full variable TrueType fonts:

- `Bitter[wght].ttf` — 328,636 bytes; `wght` 100–900. This supports the
  presentation's 600 and 700 weights.
  Copyright 2011 The Bitter Project Authors
  (`https://github.com/solmatas/BitterPro`).
  Source:
  `https://github.com/google/fonts/raw/main/ofl/bitter/Bitter%5Bwght%5D.ttf`
- `OpenSans[wdth,wght].ttf` — 532,636 bytes; `wght` 300–800 and `wdth`
  75–100. This supports the presentation's 500, 600, and 700 weights at the
  normal width (100).
  Copyright 2020 The Open Sans Project Authors
  (`https://github.com/googlefonts/opensans`).
  Source:
  `https://github.com/google/fonts/raw/main/ofl/opensans/OpenSans%5Bwdth,wght%5D.ttf`

The complete corresponding license texts are included beside the fonts:

- `OFL-Bitter.txt` — full SIL Open Font License 1.1 for Bitter.
- `OFL-OpenSans.txt` — full SIL Open Font License 1.1 for Open Sans.

## Teacher workspace family

The existing Inter files are retained for the teacher interface:

- `inter-400.ttf` — 324,820 bytes
- `inter-500.ttf` — 325,304 bytes
- `inter-600.ttf` — 326,048 bytes
- `inter-700.ttf` — 326,468 bytes

Inter is distributed under the SIL Open Font License 1.1. Presentation
surfaces should use Bitter for headings and Open Sans for body text; Inter is
not being replaced in the teacher workspace.
